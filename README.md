## 2. 赛道 B 的技术定位

### 2.1 一句话

**磁吸爬壁不是「吸得越牢越好」，而是「法向力刚好够、切向力还有余、气隙稳定可控」。**

### 2.2 力链

```
磁体 ──气隙 g──→ 钢板         产生法向吸力 F_mag（随气隙非线性下降）
        │
        ↓ 传至轮子
   法向载荷 N ──→ ① 轮胎变形与滚阻  ② 转向刮擦  ③ 垂直时的静摩擦上限 μN
        ↑
   电机 ──减速器──→ 轮         提供切向推力 F_t = 2T/r（与磁力无关，且额定远小于堵转）
```

能走的前提是 **F_t > 阻力**；能吸住的前提是 **μN ≥ mg**。两者争夺的是同一个 N。

### 2.3 因此本组的核心实验变量是「气隙」，不是「磁铁数量」

磁路会饱和、气隙主导衰减、而阻力与夹伤风险随 N 线性上升。所以目标函数是
**「单位质量可用吸力 + 可调气隙 + 不刮擦」**，不是最大拉脱力。

## 3. 关键参数与判据

| 参数                 | 值                         | 标记       | 出处 / 何时核实                               |
| -------------------- | -------------------------- | ---------- | --------------------------------------------- |
| 电机型号、电压、转速 | JGA25-370，12V，60—100 rpm | **有出处** | 手册附件 B3 磁吸参考表                        |
| 可调气隙机构         | 垫片式，四档               | **有出处** | 手册 5.5、附件 B3「可调气隙磁阵列」           |
| 整机质量 m           | ≤ 1.0 kg                   | 假设       | 部件清单 641 g + 余量；W2 称重                |
| 轮上推力 F_t         | 堵转 ≈16 N，持续 ≈6—8 N    | 假设       | 由 T=0.25—0.30 N·m、r=35 mm 算出；W3 顶秤实测 |
| 摩擦系数 μ           | ≈0.7                       | 假设       | 橡胶—干钢常见值；W3 拉滑实验                  |
| 目标法向力 N         | 不预设，由气隙扫描标定     | 待实验     | 3 mm 起逐档减小，记录「走不动」的临界气隙     |

**三个判据不能混用**：行驶判据（推力 ≥ 阻力×2）、吸附判据（静态拉脱力，只要求可重复）、垂直判据（μN ≥ mg，本阶段不做）。

> 标记说明：**有出处**＝手册或数据手册可查；**假设**＝W1 估算，按末列替换；**待实验**＝不预设，由实验标定。

## 7. 我的技术判断记录

> 这一节记录的是「我为什么这么定」，不是「手册怎么要求」。答辩时被追问的都在这里。

**① 为什么不做垂直爬升。**
属高风险实验，需专项授权与防坠审查；手册 1.3 明确「安全门未通过时，完成水平移动、静态吸附力测量与可复现的故障报告仍可作为有效成果」。我们把它列为「已评估、未授权、有方案」的下一步。

**② 为什么用垫片调气隙，而不是电机升降。**
上游 CMU Sally 用 prismatic 关节主动升降（行程 ±100 mm）。我们是教学型验证平台，只需要离散档位、不需要动态闭环；垫片方案成本低一个数量级，且**档位可复现**——这对实验比对更重要。

**③ 为什么目标法向力不预设一个数。**
水平行驶时磁吸力只增加阻力、不提供任何必要功能。因此正确做法是**扫描气隙找可行窗口**（3 mm 逐档减到「走不动」），输出的是一条曲线，而不是一个拍出来的目标值。

**④ 为什么第一批不买电池。**
省一个高风险授权项、约 180 元，以及一个宿舍充电的违规风险。台架稳压电源 + 拖线即可满足「编码器差速运动」的基础验收。
